# 🔔 НАГАДУВАННЯ РОЗРОБНИКУ: ЧЕКЛИСТ КОЖНОГО ОНОВЛЕННЯ MAFIA ROYALE

> **ПРАВИЛО №1**: Після БУДЬ-ЯКИХ доробок, правок коду, додавання персонажів чи механік — **ОБОВ'ЯЗКОВО** піднімати версію гри та оновлювати розділ новин!

---

### 📋 Чеклист випуску оновлення (крок за кроком):

1. **`version.json`**:
   - Підняти поле `"version"` (наприклад, `0.3.2` ➔ `0.3.3`).
   - Оновити `"date"` та `"title"`.
   - Додати список виконаних змін у масив `"changes": [ ... ]`.

2. **`js/data.js`**:
   - Оновити константу `export const VERSION = '0.3.x';`.
   - Додати новий запис на початок масиву `GAME_NEWS`:
     ```js
     {
       id: 'news_v0_3_x',
       version: '0.3.x',
       date: 'ДД.ММ.РРРР',
       badge: 'СВІЖИЙ ВИПУСК',
       badgeColor: '#10B981',
       title: 'Заголовок оновлення',
       summary: 'Короткий опис для гравців',
       bannerEmoji: '🗞️',
       changes: [
         'Пункти того, що було змінено або додано...'
       ]
     }
     ```

3. **`service-worker.js`**:
   - Збільшити версію кешу: `const CACHE_NAME = 'mafia-royale-vX';` (наприклад, `v8` ➔ `v9`).
   - Це змусить PWA на телефонах і в браузерах негайно підтягнути нові скрипти.

4. **Тестування та перевірка**:
   - Запустити тест `node tools/simulate.js` для перевірки симуляції.
   - Перевірити в браузері, що після перезавантаження вискакує вікно **«Що нового»** з новою версією, а на кнопці 📰 світиться червона цятка.

5. **Публікація в GitHub**:
   - `git add .`
   - `git commit -m "Оновлення v0.3.x: ..."`
   - `git push origin main`
   - Після цього оновлення стає доступним на GitHub Pages (`https://itaminx16.github.io/Mafia-Royale/`) і у гравців на телефонах!
